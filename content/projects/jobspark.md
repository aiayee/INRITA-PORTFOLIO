## Business Context

University students often face difficulty finding relevant internship and job opportunities tailored specifically to university programs and student skillsets. JobSpark was created as an online job search platform connecting students with employers.

## My Role

Database Designer & QA Tester for the Capstone Project. Responsible for relational database schema design, normalization, data consistency constraints, product backlog management, and executing quality assurance test suites.

## Approach

- **Database Architecture**: Designed a normalized MySQL database schema consisting of 15 relational tables with strict foreign key constraints, indexes, and data validation rules based on functional requirements.
- **Backlog & Requirement Mapping**: Defined 56 Product Backlog Items (PBIs) to map user stories to database entity models and application features.
- **QA & Testing Strategy**: Authored and executed 197 unit and integration test cases to validate system functionality, API payloads, and database transaction consistency.
- **Cross-functional Collaboration**: Collaborated closely with backend developers (Go / Fiber) and frontend teams (Flutter & Next.js) to debug database queries and fix data discrepancies during development.

## Results

- Delivered a robust, fully normalized database structure supporting all student job search features with zero data integrity violations.
- Verified system functionality and query performance through comprehensive QA test case execution.

## Lessons Learned

- Proper database normalization and upfront constraint definition significantly reduce bugs and data inconsistencies during application development.
- Systematic integration testing bridges the gap between database models and application user interfaces.
