## Business Context

The Event Registration system collects customer registration data for events held across Siam Piwat properties. The data is integrated into the data warehouse to support downstream analysis and data-driven decision-making.

## My Role

Lead Data Engineer / Project Owner. Led the data ingestion project from understanding source data flows and requirements to pipeline implementation and user support.

## Key Responsibilities

- Led the Event Registration data ingestion project using Airbyte.
- Worked with Application teams to understand source data flows and requirements.
- Validated ingested data before delivering it for downstream use.
- Provided data context and supported Data Science teams in using the data for analysis.
- Troubleshot data issues and supported users after implementation.
